# Second Brain — Architettura

Appunti universitari di Nadia per il corso di laurea in Architettura (Università Roma Tre).

Questa cartella e' un **vault di Obsidian**: in Obsidian scegli *Apri cartella come vault* e seleziona la cartella `nadia-secondbrain`.
Parti dalla nota `home` e leggi `guida-obsidian` per imparare a usare il vault.

Gli appunti sono organizzati per anno e semestre (`anno-1/semestre-1/...`), una cartella per materia.
Vengono scritti e sistemati con Claude Code seguendo le istruzioni in `CLAUDE.md`.
Il repository su GitHub serve come copia di sicurezza e per sincronizzare gli appunti tra computer diversi.
